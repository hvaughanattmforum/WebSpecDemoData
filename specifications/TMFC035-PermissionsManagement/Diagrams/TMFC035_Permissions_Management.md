# TMFC035 – Permissions Management

## 1. Overview

| Component Name | ID | Description | ODA Function Block |
|---|---|---|---|
| Permissions Management | TMFC035 | The Permissions Management component manages and exposes roles and related permissions. This component enables creation, modification and deletion of permissions and delegate permissions. When a specific role is assigned, a set of permissions is inherited. | PartyManagement |
