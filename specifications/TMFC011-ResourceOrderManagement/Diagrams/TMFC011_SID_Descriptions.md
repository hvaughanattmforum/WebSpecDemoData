| Resource Specification | The Resource Specification ABE contains entities that define the shared characteristics and behavior of each of the three types of Resource entities. This enables multiple instances to be derived from a single specification entity. In this derivation, each instance will use the shared characteristics and behavior defined in its associated template. A ResourceSpecification might be Physical such as a handset, Logical such as an IP address or Compound i.e. composed of Logical and / or Physical Resources such as a Box with its firmware. |  |  | GB922_Information_Framework_SID_Excel_v25.0.xlsx (v25.0) |
