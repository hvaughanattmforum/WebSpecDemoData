# TMFC011 – Resource Order Management

## 1. Overview

| Component Name | ID | Description | ODA Function Block |
|---|---|---|---|
| Resource Order Management | TMFC011 | The Resource Order Management Component manages the end-to-end lifecycle of a resource  order request. This includes validating resource availability as well as the resource order request. Other functionality includes resource order assurance,  resource order decomposition and resource order tracking, along with orchestrating  activation and the test and turn-up processes. | Production |
