# TMFC046 – Workforce Management

## 1. Overview

| Component Name | ID | Description | ODA Function Block |
|---|---|---|---|
| Workforce Management | TMFC046 | Workforce Management component provides capabilities to describe teams, organizations, skills and availability of sales / technical experts. It provides the ability to reserve time slots to carry out assigned tasks (internal or customer facing). It allows the reservation (and updates/rescheduling) of appointments and interventions. | Production |
