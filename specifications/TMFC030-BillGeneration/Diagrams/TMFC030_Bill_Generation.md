# TMFC030 – Bill Generation Management

## 1. Overview

| Component Name | ID | Description | ODA Function Block |
|---|---|---|---|
| Bill Generation Management | TMFC030 | The Bill Generation component is responsible for Party invoice management. It addresses the invoice formatting, presentation and dispatching via the appropriate means of communication. | PartyManagement |
